## 📌 Project Overview

The **Family Pulse Dashboard** provides actionable insights into regional family structures, financial metrics, gender dynamics, and living conditions. It allows users to interactively filter data to understand vulnerable demographics, housing types, and income distribution.

---

## 📊 Key Features & Visualizations

### 🎯 Key Performance Indicators (KPIs)
* **Total Families:** 1,701
* **Total Income:** $58K
* **Average Income:** $5
* **Total Members:** 11,905

### 📈 Interactive Visuals
* **Families by Country:** Column chart comparing family counts across Syria, Yemen, Iraq, and Libya.
* **Number of Cities by Country:** Donut chart breaking down city distribution.
* **Mother & No Work Families:** Treemap displaying households led by mothers with no active income.
* **Gender Distribution:** Percentage split between male (55%) and female (45%) members.
* **Housing Types:** Funnel chart showing distribution across `Flat`, `Room`, `Tent`, and `House`.

### 🎛️ Interactive Controls
* Dynamic slicers for **House**, **Country**, and **Breadwinner**.
* Single-click **Clear all slicers** button.
